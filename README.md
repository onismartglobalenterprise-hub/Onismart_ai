# Onismart AI - AI for Education & Health
**An open-source, offline-first AI tutor for underserved children in Nigeria**

Onismart AI is built by Onismart Globals, a woman-led startup in Abuja, Nigeria. It provides personalized learning and health literacy for children 5-18.

### 🌟 Features
- **LearnSmart:** Adaptive quizzes in English, Maths, Hausa & Igbo
- **HealthSmart:** Safe health information (menstrual hygiene, nutrition, malaria) - info only, no diagnosis
- Offline-first for low-end Android devices
- Child safeguarding filters

### 🛠 Tech Stack
- Python, TensorFlow, React Native
- NLP for local languages
- Frontier Tech: AI / Machine Learning
